# welcome

## 用途

首次启动时的品牌欢迎卡片，展示 AIDGET、版本号、slogan，以及一句向 Agent
创建水彩便签的示例请求。

## 填写规则

- 这是静态卡片，没有 `data-aidget-region`；修改时用 `aidget_update` 整体替换。
- 输入框文案固定为 `/Aidget 创建一个水彩风格的便签小组件`，共 22 个字符；
  改文案时应同步调整 `steps(22, end)`。
- 打字效果只使用 CSS。这个小组件 `permissions` 和 `network` 均为空数组，不要加入脚本、
  外部字体或网络资源。
- 可见文案本身就是无障碍文本；光标和发送按钮是装饰元素，不应参与朗读。

## 刷新建议

不需要刷新。动画只播放一次，结束后文字与光标保持静止；减少动态效果模式下
直接显示完整文案。用户熟悉后可以直接删除这个小组件。

## 外观

窗口是完全透明的主机，外壳不画背景、边框或模糊。`.welcome` 自己提供卡面，
所以改 `style.css` 就是在改桌面上的最终效果。不要给卡面加
`backdrop-filter`：macOS 在拖拽和失焦时会停掉桌面模糊，卡面会突然变成全透明。
